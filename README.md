# daily-quote-app

Trang web hiển thị câu trích dẫn ngẫu nhiên, viết bằng HTML, CSS và JavaScript thuần.

## Tính năng
- Hiển thị câu trích dẫn ngẫu nhiên khi mở trang (không lặp lại câu vừa hiện)
- Lời chào theo giờ trong ngày
- Nút đổi câu, hoặc bấm phím `N`
- Nút copy câu trích dẫn
- Lưu câu yêu thích vào trình duyệt (localStorage) và xem lại danh sách
- Tự chuyển giao diện tối theo cài đặt của hệ thống
- Nút "Câu của ngày": mỗi ngày một câu cố định
- Lọc câu theo tác giả
- Xóa từng câu hoặc tất cả câu yêu thích
- Thêm câu trích dẫn của riêng bạn (lưu trong trình duyệt), có kiểm tra độ dài và trùng câu
- Hiển thị tổng số câu trích dẫn
- Xóa toàn bộ câu đã thêm
- Nhấn Enter trong ô nhập để thêm câu; phím tắt `N` không kích hoạt khi đang gõ
- Nhớ tác giả đang lọc sau khi tải lại trang
- Tải danh sách câu yêu thích về file `.txt`
- Hỗ trợ trình đọc màn hình (ARIA) và viền focus khi dùng bàn phím
## Cách chạy
Mở file `index.html` bằng trình duyệt.
