# daily-quote-app

Trang web hiển thị câu trích dẫn ngẫu nhiên, viết bằng HTML, CSS và JavaScript thuần.

## Tính năng
- Hiển thị câu trích dẫn ngẫu nhiên khi mở trang (không lặp lại câu vừa hiện)
- Lời chào theo giờ trong ngày
- Nút đổi câu, hoặc bấm phím `N`
- Nút copy câu trích dẫn
- Lưu câu yêu thích vào trình duyệt (localStorage) và xem lại danh sách
- Tự chuyển giao diện tối theo cài đặt của hệ thống

## Cách chạy
Mở file `index.html` bằng trình duyệt.
