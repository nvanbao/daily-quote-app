# daily-quote-app

Trang web hiển thị câu trích dẫn ngẫu nhiên, viết bằng HTML, CSS và JavaScript thuần.

## Tính năng
- Hiển thị câu trích dẫn ngẫu nhiên khi mở trang
- Nút đổi sang câu khác (không lặp lại câu vừa hiện)
- Nút copy câu trích dẫn

## Cách chạy
Mở file `index.html` bằng trình duyệt.
